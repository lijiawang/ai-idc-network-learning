## 统一口径

- 每台服务器八张 GPU、八个 400G 计算端口，交换机提供 64 个可同时工作的 400G 逻辑端口。
- 容量方法可用于符合这些条件的 RoCEv2 或 IB 网络，配置与认证范围分别说明。
- 一个 SU 按 32 台服务器、256 张 GPU 计算；一个建设 Pod 按四个 SU、1024 张 GPU 定义。
- 第二篇的独立两层 Pod 与第三篇向 Core 上联的三层 Pod 是不同设计选择，不能按相同接法连续扩展。
- 十个 Pod 是 10240 卡。160 台 Core 只作为当前端口容量下限；256 台明确属于按十六个 Pod 预留的示例，不写成十个 Pod 的必需配置。
- 设备数量与逻辑拓扑为教学算例，不能替代施工接线、路由验证和性能验收。
