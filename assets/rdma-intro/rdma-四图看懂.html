四张图看懂 RDMA

从数据路径、对象模型、操作语义到 RoCEv2 拥塞闭环：先看全景，再读正文。

先看数据路径

  • • RDMA 减少协议栈中转与额外复制
  • • RNIC 执行 DMA 与传输快路径
  • • CPU 仍负责创建、注册与同步

再记三个对象

  • • MR：已授权、已映射的内存
  • • QP：提交 Send / Read / Write 的队列
  • • CQ：检查请求是否真正完成

最后分清通知

  • • 普通 Write 不会通知远端应用
  • • Write with Immediate 会产生远端 Receive CQE
  • • 本地成功 CQE 不等于业务已消费
